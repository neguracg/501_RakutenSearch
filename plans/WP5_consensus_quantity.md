# 指示書 WP5 — 数量の信頼度を「解釈の一致」で決める（規則足し算の打ち切り）

## なぜ（3周目の反省）

WP3→WP4 と規則を足すたびに、別の経路で「高信頼のまま誤った総量」（偽の最安＝金銭の誤判定）が出た。
verifier の実測（実在らしい題名 232件）で、WP4 は誤り 16→50件に**悪化**した（A1′: 言い直した総数を因子として掛ける／A2: P・ヶ・点が「1080P」「12ヶ月保証」「10P還元」を拾う）。
規則を順に当てて最初に当たった解釈を high にする作りでは、規則を足すほど誤読経路が増える。原則を反転する。

## SPEC §7 に入れる原則（最上位。個別規則より優先）

- **P0 一致原則**: 総数（個数×内容量）の候補を、独立した読み方で全部出す——①×・入数でつながった鎖の積 ②括弧内・「計/合計/全/=」・後続の同じ数え語で書かれた総数（言い直し）③単独の個数・内容量。**全ての候補が同じ総数を指す時だけ high**。1つでも食い違えば low（単価不明）。失敗の向きは常に「偽の最安」ではなく「単価不明」。
- **P1 言い直し**: 内訳（a×b…）の積と**等しい**後続・括弧内の個数は総数の言い直しで、因子にしない（「12ロール×4パック(48ロール)」→48、「64枚×3パック(192枚)」→192、「納豆 45g×3パック×16個 (48パック)」→48パック×45g）。
- **P2 空白連結の制限**: ×の無い空白だけの連結（W1）は、まだ1因子の時だけ足す。2因子以上の鎖には足さない。
- **P3 文脈の要る数え語**: P・ヶ・点・回分 は**個数の連結位置**（×の直後、入数の直後、「N点セット」）でだけ数え語にする。「ヶ月」は数え語にしない。「1080P」「60P」「10P還元」「2点購入」「12ヶ月保証」「3ヶ月分」は数量にしない。
- **P4 容器語の同数**: 「3個入り 400ml×3セット」のように同じ数でも外側が容器語（セット・ケース・パック・箱・袋）なら掛け算（9）として扱う。ただし P1（積と等しい後続）が優先。
- 既存の S1〜S11・W1〜W5 は P0〜P4 と矛盾する時は P が優先。矛盾箇所は SPEC 上で注記して整理する。

## 確定（tester の X1〜X5 への回答。SPEC に同文で入れる）

- X1 P3 を次のとおり精密化する（既存試験「ティッシュ 12P」→12・「ケーキ 6ヶ」→6・「ギフト 5点」→5・「12回分」→12 は**正しいまま**）:
  - P は、数字が 1〜99 で、直後が還元・倍・UP・アップ・ポイント・増量 でない時だけ数え語（「1080P」「2160P」は数えない。「60P」は数えるが、他の個数と食い違えば P0 で low）。
  - ヶ は直後が「月」の時は数えない。点 は直後が 購入・以上・まで・で の時は数えない。
  - 回分 は S1 のまま（計量値がある時は数えず、無ければ個数）。
- X2 別語の言い直し（「12ロール×4パック(48個)」）も積と等しければ言い直し＝48・high。
- X3 鎖の後ろに積と無関係な数え語付きの数がある（「12ロール×4パック 5冊」）→ 候補が食い違うので low。
- X4 容器語でない同数（「3個入り 3冊」）→ low。
- X5 「入数の直後の P/ヶ/点」は「12本入 3P」のように入数の直後に来る形（→36）。
