# 買い物リサーチツール / 501_RakutenSearch

個人の買い物を効率化する汎用の商品検索・比較ツール。特定の商品ジャンルに限定しない。

## 現在の状態

開発準備中。API利用登録・接続準備の段階であり、商品検索CLI本体は未実装。
予定機能はキーワード検索、商品情報・URL整理、重複排除、利用条件に適合する範囲でのCSV整理とChatGPT比較補助。
非公開ローカル利用・保存期間・外部AI転送の利用条件は確認中。
