# DECISIONS


## 2026-11-04 説明ページ
- 対象は個人の買い物全般。ソーラーパネルは最初の検索例。
- ユーザーの指示に基づき既存リポジトリを利用し、GitHub Pagesに静的説明ページを公開する方針。
- CLI本体・認証情報・商品データは公開ページへ含めない。
- API利用条件の適合確認と接続試験は別途必要。

## 2026-11-05 Phase 1 着手
- 最終形は楽天・Yahoo!・Amazon・ヨドバシの横断比較。モール固有処理は adapter に閉じ込める（SPEC §3）。
- ChatGPT 接続は MCP サーバーを主軸（個人プランでカスタムGPT新規作成不可のため GPT Actions は採らない）。Plus からの実接続は未検証。
- 定番品（例: キャンプ場のトイレットペーパー）の入り数違い比較を中核機能として Phase 1 に含める。
- 単価・最安判定は誤ると実害が出るロジックのため、独立試験（ブラインド）で判定する。
- 楽天規約の個人専用運用は未解決のまま。公開アプリと偽装する方法は採らない。
